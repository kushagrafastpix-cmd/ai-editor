Unified Structure for All Tracks:

Track → Section → Segment → Content

Track Level

{ "id": "track-xxx", "trackType": "XXXTrack", "sections": [...] }

Section Level

{ "id": "section-xxx", "sectionDuration": { "sO": 0, "eO": 5760, "type": "TS" }, "sectionTimeline": { "in": 0, "out": 5760 }, "segments": [...], "propertiesMap": {...}, "sceneId": "S.xxx" }

sectionDuration = time in source video | sectionTimeline = position on edited timeline

Segment Level

{ "id": "segment-xxx", "contentType": "XXX", "content": {...}, "duration": { "sO": 0, "eO": 5760, "type": "TS" }, "timeline": { "in": 0, "out": 5760 } }

Final opusresultjson.js

All tracks in unified structure ready for rendering

Key Points:

  • Unified Flow: All 10 track types follow the exact same generation flow
  • Common Structure: All tracks share the same hierarchical structure (Track → Section → Segment → Content)
  • Time Format: All timing uses {sO, eO, type: "TS"} format
  • Serialization: Converts "living" objects (with methods) to "dead" data (plain JSON)
  • Cleanup: Ensures only complete, valid edits are exported
