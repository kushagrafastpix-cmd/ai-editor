Track JSON Structure Explanation

Understanding the structure of opusresultjson.js - How all track types are organized

Root → Tracks → Sections → Segments → Content

Root Level Structure

{ "targets": ["VIDEO_PREVIEW", "VIDEO_FILE"], "clipBody": { "editingScript": { "tracks": [/* Array of track objects */] }, "renderPreferenceOverride": {/* Render settings */} } }

Root Structure

  • targets: Array specifying output types (preview, final video file)
  • clipBody: Contains the complete editing specification
  • editingScript: Contains all tracks that define the video composition
  • tracks: Array of track objects (can contain 0-10 different track types)

Track Types (10 Different Types)

KeyFrameTrack - Main video track with keyframes
CaptionTrack - Captions/subtitles
EmojiTrack - Emoji overlays
BRollTrack - B-roll footage
MediaTrack - Media overlays
VideoEffectTrack - Transitions/effects
TextOverlayTrack - Text overlays
VoiceOverTrack - Voiceover audio
AudioTrack - Voice enhancement
AudioTrack - Background music/sound

Track Level Structure

{ "id": "track-00AbwZ", // Unique track identifier "trackType": "KeyFrameTrack", // Type of track (one of 10 types) "sections": [/* Array of section objects */] // Sections within this track }

Track Properties

  • id: Unique identifier for the track (format: "track-xxxxx")
  • trackType: Specifies what type of track this is (determines content structure)
  • sections: Array of sections that make up this track (each section represents a time segment)

Section Level Structure

{ "id": "section-iVVns4", // Unique section identifier "sectionDuration": { // Duration in source video "sO": 0, // Start offset (milliseconds) "eO": 5760, // End offset (milliseconds) "type": "TS" // TimeStamp type }, "sectionTimeline": { // Position on edited timeline "in": 0, // Timeline start position "out": 5760 // Timeline end position }, "segments": [/* Array of segment objects */], // Segments within this section "propertiesMap": { // Metadata (varies by track type) "subType": "intro", "resourceId": "cJVJ9OhkIT", "resourceType": "video", /* ... more properties ... */ }, "sceneId": "S.intro" // Scene identifier }

Section Properties

  • id: Unique identifier for the section
  • sectionDuration: Time range in the source video (where the content comes from)
  • sectionTimeline: Position on the edited timeline (where it appears in final video)
  • segments: Array of segments that contain the actual content
  • propertiesMap: Metadata about the section (resource info, type, URLs, etc.)
  • sceneId: Identifier linking to a scene (e.g., "S.intro", "S.000")

⏱️ Time Format Explanation

sectionDuration vs sectionTimeline:

  • sectionDuration: References time in the original source video (before editing)
  • sectionTimeline: References time in the final edited video (after cuts/edits)
  • Example: A section might use seconds 10-20 from source video, but appear at seconds 5-15 in final video

Segment Level Structure

{ "id": "segment-pfV5wE", // Unique segment identifier "contentType": "KeyFrameGroup", // Type of content (varies by track) "content": {/* Content object - structure varies by contentType */}, "duration": { // Duration in source "sO": 0, "eO": 5760, "type": "TS" }, "timeline": { // Position on timeline "in": 0, "out": 5760 } }

Segment Properties

  • id: Unique identifier for the segment
  • contentType: Determines the structure of the content object (see Content Types below)
  • content: The actual content data (structure varies based on contentType)
  • duration: Time range in source (similar to sectionDuration)
  • timeline: Position on edited timeline (similar to sectionTimeline)

Content Level Structure (Varies by Track Type)

The content object structure depends on the contentType, which is determined by the trackType

KeyFrameGroup (KeyFrameTrack)

{ "layoutType": "Fill", "keyFrameContents": [{ "resourceUri": "https://...", "resourceType": "video", "cropAreas": [{"xPct", "yPct", "wPct", "hPct"}], "analysisResult": {"face", "people", ...} }] }

Caption (CaptionTrack)

{ "textElements": [{ "id": "text-xxx", "text": "Caption text", "duration": {"sO", "eO"}, "timeline": {"in", "out"}, "color": 0 }] }

VideoEffect (VideoEffectTrack)

{ "effectType": "crossFade", "effectParams": [{ "alpha": 1, "effectTimestamp": 0, "mode": "bezier" }] }

BRoll (BRollTrack)

{ "bRollElements": [{ "brollType": "Stock", "keyword": "debt", "broll": { "sourceId", "url", "previewUrl" }, "cropArea", "targetArea" }] }

VoiceOver (VoiceOverTrack)

{ "textElements": [{ "text": "word", "duration", "timeline" }] }

Emoji (EmojiTrack)

{ "emojiElements": [{ /* Emoji data */ }] }

Content Type Mapping

  • KeyFrameTrack → contentType: "KeyFrameGroup" → Contains video keyframes with crops and analysis
  • CaptionTrack → contentType: "Caption" → Contains text elements for captions
  • VideoEffectTrack → contentType: "VideoEffect" → Contains effect type and parameters
  • BRollTrack → contentType: "BRoll" → Contains B-roll elements with media URLs
  • VoiceOverTrack → contentType: "VoiceOver" → Contains text elements for voiceover
  • EmojiTrack → contentType: "Emoji" → Contains emoji elements
  • MediaTrack → contentType: "Media" → Contains media overlay data
  • TextOverlayTrack → contentType: "TextOverlay" → Contains text overlay data
  • AudioTrack → contentType: "Audio" → Contains audio track data

Key Takeaways

  • Unified Structure: All 10 track types follow the same hierarchical structure: Track → Section → Segment → Content
  • Time References: Two types of time references:
    • duration/sectionDuration = time in source video
    • timeline/sectionTimeline = position in final edited video
  • Time Format: All time values use {sO, eO, type: "TS"} format (milliseconds)
  • Content Variation: The content object structure varies by contentType, which is determined by trackType
  • Multiple Sections: Each track can contain multiple sections, each representing a different time segment
  • Multiple Segments: Each section can contain multiple segments, allowing complex compositions
